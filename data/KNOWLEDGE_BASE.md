# CivicPulse Knowledge Base (Agent 4 SOPs)

Agent 4 (Resolution Planner) uses a Retrieval-Augmented Generation (RAG) architecture to dynamically pull relevant Standard Operating Procedures (SOPs) based on the citizen's report. 

This enables the AI to generate accurate SLAs and professional civic briefs backed by real municipal regulations, rather than hallucinating generic advice.

## Database Schema

The knowledge base is stored in your Supabase database in the `sops` table. It uses `pgvector` for semantic search.

```sql
CREATE TABLE IF NOT EXISTS sops (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  category text NOT NULL,
  content text NOT NULL, -- The actual SOP text
  embedding vector(768)   -- The vector embedding generated by Google's text-embedding-004
);
```

When Agent 4 runs, it converts the citizen's report into an embedding using Gemini's `text-embedding-004` model. It then runs a cosine similarity search against the `sops` table using the `match_sops` Postgres function to find the top matching procedures.

## How to Update the RAG Data

You can easily update or add new SOPs to the knowledge base! You just need to insert new rows into the `sops` table and generate the embedding.

### Option 1: Via the Application API (Recommended)

You can create a simple admin script or API route in Next.js that takes your raw markdown/text, calls the embedding API, and inserts it into Supabase.

```typescript
import { generateEmbedding } from '@/lib/ai/client';
import { createServiceClient } from '@/lib/db/server';

async function insertSOP(category: string, text: string) {
  const supabase = createServiceClient();
  const vector = await generateEmbedding(text);
  
  await supabase.from('sops').insert({
    category: category,
    content: text,
    embedding: vector
  });
}
```

## Verifying the RAG

If Agent 4 says `No highly relevant SOPs found`, it means either:
1. The `sops` table is empty.
2. The `match_sops` Postgres function hasn't been created in Supabase yet.
3. The citizen report's embedding didn't meet the similarity threshold (currently `0.5`).
